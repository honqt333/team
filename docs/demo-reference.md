# مرجع بيانات القبول المحلية

يُشغّل المرجع صراحةً بعد تهيئة قاعدة التطوير وتوفر الباقات. ويستخدم اختبار القبول قاعدة SQLite معزولة.

```bash
php artisan db:seed --class=TestingEnvironmentSeeder
php artisan test tests/Feature/DemoReferenceTest.php tests/Feature/Settings/BranchesIndexCrudTest.php
```

يتعرف المرجع على كل سيناريو بمعرّف المستأجر، وينشئ السيناريو الناقص كاملاً في معاملة واحدة. إعادة التشغيل تحافظ على بيانات السيناريوهات الموجودة وتواريخها، بما فيها العمليات التي أضافها المستخدمون يدوياً. تواريخ الجدول تخص لحظة إنشاء العينة.

| معرّف المستأجر | الغرض عند الإنشاء |
|---|---|
| active-workshop | ورشة احترافية نشطة تضم العملاء والمركبات والفنيين والرواتب الأساسية والموردين والمخزون وكروت العمل. تشمل العينة الجديدة كرتاً منجزاً وفاتورة مصدرة ودفعة مرتبطة به. |
| new-workshop | تجربة سارية لمدة 14 يوماً |
| expiring-workshop | اشتراك أساسي مدفوع ينتهي خلال ثلاثة أيام |
| expired-workshop | اشتراك أساسي منتهٍ ومستأجر للقراءة |
| new-tenant | مستأجر مسجّل قبل بدء أي اشتراك |
| trial-just-ended | تجربة منتهية ومستأجر للقراءة |
| trial-ending-soon | تجربة تنتهي خلال يومين |

## حد الفروع

تضبطه إدارة المنصة من صفحة الباقات. يقرأ إنشاء الفرع قيمة JSON ـ `plans.limits.max_centers` من الاشتراك المختار، ثم المفتاح التاريخي `centers` عند غياب المفتاح الأساسي. الحد الافتراضي فرع واحد، وتُعامل القيمة 999 فما فوق كغير محدودة. تشمل المقارنة الفرع الرئيسي والفروع غير النشطة الموجودة. القيم قابلة للتغيير من لوحة الباقات.

يعتمد الاختيار الحالي على الحالات active وtrial وtrialing، وكون ends_at في المستقبل أو فارغاً. لا يفحص هذا الاستعلام trial_ends_at بصورة مستقلة. اختبار الفروع يتحقق من قيم الباقة وأولوية المفاتيح، والاختبارات المنفصلة لدورة الاشتراك تغطي الانتقال بين الحالات.

## اختبارات المجالات المرتبطة

- BranchesIndexCrudTest وWorkOrderQuoteBranchIsolationTest للصلاحيات ونطاق الفروع.
- SubscriptionLifecycleAndRenewalTest للتجربة والتجديد وفترة السماح.
- FinancialSafetyAuditAcceptanceTest للتقارير المالية والصندوق والفترة الضريبية.
- InventoryTransferIntegrityTest لسلامة تحويلات المخزون.
- PayrollCenterIsolationTest لعزل مسيرات الرواتب واعتمادها.

التعبئة العامة DatabaseSeeder للتهيئة الأساسية. بقيت أدوات الأداء والعزل وسيناريوهات الفوترة القديمة متاحة لمن يستدعيها صراحةً؛ تشغيل المرجع لا يستدعي مجموعات الأداء والعزل أو ينشئ مستأجراً منفصلاً لكل اختبار آلي.
