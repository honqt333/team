# مراجعة إغلاق ملاحظتي الفترة الضريبية والصندوق

أعيدت قراءة الخدمات واختبارات القبول الخمسة الجديدة. لم يعدل المراجع كود التطبيق أو بيانات العمل.

## الفترة الضريبية

القسم الخاص بالمعاملات الإدارية يقبل المعتمدة المستقلة فقط بقيدي invoice_id IS NULL وpurchase_invoice_id IS NULL. بذلك لا تعود ضريبة الفاتورة الملغاة أو المسودة أو المحذوفة عبر هذا القسم، وتبقى الفواتير المؤهلة في مصدر الفواتير. الاختبارات تتضمن حالة مستقلة موجبة للحفاظ على شمولها. لا يوجد في المصدر المقروء استمرار للعيب المثبت سابقاً.

## تقرير الصندوق

المعاملات الإدارية المستقلة المعتمدة تظهر فقط مع all أوcash. المعاملة المرتبطة بفاتورة لا تتحول إلى حركة نقدية دون دفعة؛ المدفوعات الفعلية مصدرها payments وتخضع لمرشحها. استبدل النص الثابت الخاص بالمركز بمفتاح الترجمة. يطابق هذا معالجة R06 والحركات النقدية الوهمية ضمن النطاق المراجع.

## ملاحظة على دقة الاختبارات

بعض اختبارات الضريبة تبحث بـtransaction_id فقط رغم تعدد أنواع المصادر. الأفضل تقييد البحث بـtransaction_type أيضاً لمنع تصادم معرفات جدولين وحدوث فشل مضلل مستقبلاً. لا يبطل هذا الإصلاح؛ التأهيل المستقل والحالات المغطاة قُرئت في المصدر نفسه.

هذا الإغلاق يخص العيبين المحددين ولا يثبت مراجعة كل النظام يدوياً أو صحة كل القواعد الضريبية والمالية. لا تعديلات على البيانات ولا ترحيل لفترات قديمة ضمن هذه الجولة.
