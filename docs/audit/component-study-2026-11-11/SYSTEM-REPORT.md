## حدود التعميم

- للبوابة العامة مكونات AuthShell وBrandMark وWizardStepper، وللموظف والمنصة تخطيطان مستقلان. يمكن مشاركة حقل أو شارة بعد مراجعة الهوية والصلاحيات والبيانات المعروضة. لا يوجد في الجرد دليل يبرر دمج هذه التخطيطات.
- تستخدم 97 وحدة Vue وسم DataTable مباشرة. تشمل هذه الوحدات جداول structured التي تملك الصفحة فيها تعريف الصفوف. قياس توحيد البحث والفرز والترقيم يتطلب مراجعة عقد كل قائمة.
- PDF والبريد وواجهات Vue بيئات عرض مختلفة. المشاركة المناسبة في الهوية والترجمات والقيم المعروضة تحافظ على استقلال قوالب الطباعة والبريد.
- أرقام الجرد لا تقيس زمن التوفير ولا تثبت المطابقة البصرية أو التفويض. لم تتضمن هذه الدراسة تشغيل سيناريو قبول لكل دور أو تعديل ملفات التطبيق.

## دفعات التنفيذ المقترحة

1. نموذج الدفع المشترك وحقل استيراد الملفات. قياس النجاح بإزالة ازدواجية الحقول ودعم مساري الدخول ونتيجة الاستيراد الجزئية.
2. المرفقات وترقيم بوابة الموظف. فحص صلاحيات القراءة والكتابة وروابط الصفحات.
3. أغلفة الحقول ومرشحات الفترة ومنتقي مشتريات يدعم الرصيد الصفري. اختبار كل مستهلك قبل التوسع.
4. المؤشرات والشارات وتخطيط الأخطاء. مقارنة النسختين العربية والإنجليزية على الهاتف وسطح المكتب.

يُضاف المكوّن الجديد إلى سجل المشروع بعد وجود مستهلكين فعليين، وعقد واضح للقيم والأحداث، واختبار للفروق التي دفعت إلى فصل المكوّن عن صفحته. هذا معيار مقترح لهذه الدفعات.
